# Ритм

Личный трекер тренировок тазового дна для мужчины с подтеканием после полного окончания мочеиспускания (PMD).

Статическое веб-приложение для GitHub Pages: русский интерфейс, IndexedDB, офлайн-кэш Service Worker, установка на экран «Домой». Без сторонних библиотек, аналитики, аккаунта приложения и серверной базы. Размещение на GitHub Pages с публичным репозиторием — бесплатно в рамках его условий.

## Установить на iPhone

1. Откройте **https://listalimovrasul-cmyk.github.io/ritm-tracker/** в **Safari**. Для первой загрузки нужен интернет. Не используйте приватную вкладку.
2. Нажмите **«Поделиться» → «На экран “Домой”»**. Если предложен переключатель «Открывать как веб-приложение», включите его. Название — «Ритм».
3. Запустите приложение с новой иконки при включённом интернете. Выберите посильную нагрузку и прочитайте технику / условия остановки.
4. Откройте **«Данные»**, дождитесь сообщения **«Файлы готовы для работы офлайн»**.
5. Закройте приложение, включите авиарежим и проверьте повторный запуск, памятку, запись дневника и тренировку.
6. Сделайте первую резервную копию: **«Данные» → «Экспорт данных в JSON» → «Поделиться JSON…» / «Скачать JSON»**. Проверьте наличие файла вне приложения и только затем подтвердите копию.

Установленное веб-приложение может иметь отдельное хранилище от вкладки Safari. Если уже внесли записи до установки, перенесите их через JSON. Mac, Xcode, платный Apple ID и обновление подписи каждые 7 дней не нужны.

## Что умеет

- Таймер медленных / быстрых сокращений с полным расслаблением, паузой и немедленной остановкой при дискомфорте.
- Сохранение черновика на границах фаз. После ухода в фон, блокировки или большой задержки таймера повторы не засчитываются. Возобновление: 5 с восстановления, затем текущая фаза с начала.
- Дневник: число мочеиспусканий, после скольких были капли, беспокойство 0–10, дискомфорт и заметка. Отсутствие дня не считается отсутствием симптомов. Это личная шкала, а не валидированный опросник.
- Индивидуальный старт, ручное подтверждение предложения повышения, снижение нагрузки и защитная пауза.
- Тёмная тема, системные шрифты, крупный текст, отдельный переключатель размера, safe areas и крупные кнопки.
- Офлайн-памятка с проверяемыми ссылками на источники.

## Хранение и резервные копии

**IndexedDB** хранит структурированные записи и поддерживает транзакции. Успех сохранения показывается после завершения транзакции, а не после отдельного `put`. В случае ошибки нет подмены базы временным хранением: приложение сообщает об ошибке; таймер при ошибке сохранения ставится на паузу.

База находится только на устройстве и привязана к веб-источнику. Для разных путей приложений используется отдельное имя базы, но пути одного GitHub Pages-источника не являются отдельными границами безопасности. Не меняйте веб-адрес / домен без предварительного экспорта: другой origin получает другое хранилище. Приложение запрашивает постоянное хранение; браузер может не разрешить его.

iOS / Safari, очистка данных сайта, удаление веб-приложения и нехватка места могут привести к потере локальных записей. Поэтому **сохраняйте JSON каждые 14 дней**, а также перед сменой адреса и переустановкой. Для локальной копии используйте «На моём iPhone», внешний накопитель или AirDrop на Mac. Копия на другом устройстве защищает также от потери телефона. JSON не зашифрован отдельно.

Приложение не может узнать, действительно ли браузер сохранил скачанный файл. После проверки файла подтвердите дату копии вручную. Отмена системного меню сама по себе не обновляет дату backup.

**Импорт:** выберите JSON, проверьте состав и подтвердите. При совпадении ID тренировки или даты дневника остаётся локальная версия. Другие записи добавляются одной транзакцией. Повторный импорт не создаёт дубликаты. Восстановление плана — отдельная опция; действующая пауза из-за симптомов не снимается. После объединения сделайте новую копию.

Проверяется формат `ritm-local`, версия 1, даты, диапазоны, уникальность, согласованность оценок и завершённости. Лимиты: 20 МБ, 30 000 тренировок, 15 000 дней, 2000 символов заметки. Даты — ISO 8601 UTC. Формат совместим с основными полями нативного проекта «Ритм»; настройки внешнего вида добавлены как необязательные поля. Резервные копии **никогда не загружайте в репозиторий**.

## Напоминания

Напоминание о копии показывается внутри приложения каждые 14 дней от последней подтверждённой копии. PWA без push-сервера не обещает уведомления, пока закрыто. Во вкладке «Данные» доступен файл `.ics`: добавьте его в выбранный календарь для повторного напоминания раз в 2 недели. Разрешения / уведомления Календаря задаются в iOS; расписание события не сдвигается автоматически после экспорта.

## Клиническое основание

Для первичного мужского PMD единой доказанной оптимальной схемы прогрессии нет. NICE CG97, 1.3.1 рекомендует обучение **urethral milking**. PFMT может помочь, но профильная доказательная база невелика.

Начало по умолчанию: 5 медленных × 3 с, 3 быстрых, 1 раз/день. В первом запуске нагрузка выбирается по качеству выполнения. Между медленными — `max(6 с, удержание)`, после быстрых — 3 с. Эти числа являются настройками приложения, а не дозировкой из клинического испытания.

Повышение предлагается после ≥7 календарных дней на нагрузке, при ≥5 качественных днях из последних 7 с выполнением дневного плана и без зарегистрированного дискомфорта. Один параметр за шаг: частота до 3 раз/день, затем удержание до 10 с, медленные до 10 и быстрые до 10. Правило не валидировано как алгоритм лечения PMD. Повышение необязательно; максимум не является целью лечения. К 12 неделям оцените пользу со специалистом, при ухудшении — раньше.

Источники проверены 10.11.2026:

- [NICE CG97, рекомендации](https://www.nice.org.uk/guidance/cg97/chapter/recommendations).
- [EAU, Male LUTS, Disease Management](https://uroweb.org/guidelines/management-of-non-neurogenic-male-luts/chapter/disease-management).
- [Albakr et al. Систематический обзор, 2024; PMID 38032134](https://pubmed.ncbi.nlm.nih.gov/38032134/).
- [Paterson et al. РКИ, 1997; PMID 9202555](https://pubmed.ncbi.nlm.nih.gov/9202555/).
- [Dorey et al. Мужчины с эректильной дисфункцией, 2004; PMID 15658735](https://pubmed.ncbi.nlm.nih.gov/15658735/).
- [NHS DynamicHealth, упражнения для мужчин](https://www.dynamichealth.nhs.uk/help-and-advice/pelvic-health/pelvic-floor-exercises-for-men/).

При невозможности помочиться нужна срочная помощь. Кровь в моче, лихорадка, боль, жжение, слабая струя, неполное опорожнение требуют медицинской оценки. PMD сам по себе не доказывает слабость мышц; при боли / постоянном напряжении укрепление может не подходить. Схемы женского стрессового недержания не выдаются здесь за прямое основание дозировки для мужского PMD.

## Публикация и обновление

GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**. Файл `.nojekyll` отключает обработку Jekyll. Сборка и npm для работы сайта не нужны. В репозитории размещаются только исходники и ресурсы, без личных записей. GitHub может вести технические журналы посещений, но введённый дневник приложение на сервер не отправляет.

Все URL ресурсов относительные, поэтому приложение работает и в `/ritm-tracker/`. При изменениях кода **измените VERSION в `sw.js`**, чтобы обновился офлайн-кэш. Новая версия ждёт; пользователь устанавливает её во вкладке «Данные». Не меняйте имя базы, поля и формат backup без миграции. Активная тренировка не перезагружается автоматически.

## Проверка

В среде подготовки выполнены 20 Node-проверок логики / транзакций с fake-indexeddb, а также браузерные проверки сохранения после перезагрузки, JSON, остановки, офлайн-запуска, тёмной темы и текста 150%. Конкретные движки и итоговая проверка опубликованного адреса фиксируются в сообщении о выпуске. Проверка настоящего iPhone / Safari пользователем всё равно нужна: эмуляция размера экрана не заменяет устройство.

Для локального просмотра нужен HTTP-сервер, а не открытие HTML как файла. Например, при установленном Python: `python -m http.server 8000`, затем `http://localhost:8000/`. Интернет-зависимостей у приложения нет; `package.json` только задаёт тип JavaScript-модулей.
